# Новая статья по предоставленным источникам

Прочитайте [порядок создания черновика](../../../docs/editorial-creation-workflow.md). Он определяет согласование плана, запись статьи и проверки. При продолжении сверяйте текущее досье и утверждение по этому порядку.

1. Уточните тему и задачу читателя, если их недостаточно для исследования. Сверьте список предоставленных материалов и ограничения на дополнение. При пустом списке запросите исходники или согласуйте переход к [режиму по теме](../article-from-topic/SKILL.md).
2. Примените [research](../research/SKILL.md) к новому brief. Проверьте относящиеся к теме фрагменты и отметьте статус каждого предоставленного материала как origin: provided. Для прочитанного сохраните точное место, применимую версию и связи Source ID с существенными тезисами. Дополнительные источники используйте в разрешённых пределах и отмечайте как origin: found_now.
3. Отразите недоступность, частичный доступ и расхождения. При существенном пробеле покажите, какой тезис остаётся без доказательства, и запросите нужный материал или предложите ограниченный объём на согласование. При запрете дополнительных источников сохраните границу.
4. Покажите версию плана по общему порядку. После явного утверждения именно этой версии создайте один черновик с draft: true и передайте его в [article-review](../article-review/SKILL.md) после обязательных проверок.
