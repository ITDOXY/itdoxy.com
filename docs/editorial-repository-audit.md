## Обзор метаданных архива

В `content/posts/` обнаружено 105 Markdown-материалов без `_index.md`. Проверка наличия ключей в YAML-front-matter дала: `slug`, `date`, `categories`, `draft` — у 105; `author` и `authorUrl` — у 8; `description` и `lastmod` — у 0; `cover` — у 3; `images` — у 96; `tags` — у 79.

Это текстовая инвентаризация ключей, не полноценная валидация YAML, SEO или авторства. Наличие meta description в собранном HTML не доказывает наличие редакторского description. Отсутствие автора в старом файле не разрешает назначить нового: возможен fallback сайта.
